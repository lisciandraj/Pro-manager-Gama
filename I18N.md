# GAMA interface languages

Spanish is the default. Configuration (the gear next to the notification bell in the top bar) opens on its Language section, which offers French, English and Spanish, with accessible names and selected-state buttons. Configuration is available to every signed-in role including clients; the window follows the chosen language at once, accessible names included. Module administration lives in the separate administrator-only Access settings module. Language controls also appear in the login dialog, but never in the header. The choice is saved per browser in `gama_language_v1` and synchronised across its tabs. Switching language updates labels in place: no navigation, form reset, data write or camera restart.

## Translation sources

`locales/catalog.tsv` contains reviewed source / French / English strings. `python scripts/build-i18n.py` generates `gama-i18n-catalog.js` and annotates static labels in the HTML and module templates. The compiler is idempotent; both sources and output are committed. No translation service or new runtime dependency is needed.

- `data-gi=<key>` translates only the matching direct static text node, not child data.
- Text that follows an empty tag such as `<br>` or a checkbox `<input>` belongs to the parent element. The compiler wraps it in its own `<span data-gi=<key>>`, because a key left on the empty tag would never reach the text.
- `data-gi-placeholder`, `data-gi-title`, `data-gi-aria-label` translate presentation attributes.
- `data-gi-live` opts a dynamic presentation node into exact-label lookup. Use only for UI labels, enum display names, counts and messages, never customer/product names, addresses, free-text notes, filenames or user-generated content.
- `translate="no"` or `data-gi-ignore` explicitly protects a subtree.
- `GamaI18n.t(source)` is available for native confirmation messages and other non-DOM UI.
- Numbered placeholders such as `{0}` accept numeric display values, dates and times (`Creada el {0}`, `Faltan {0} km`). Unknown messages retain their source rather than guessing a translation.
- Details composed by the server (alerts, action centre) are translated piece by piece: each ` · ` segment separately, and in `Label: value` only the label, so values, dates and amounts never change. Add the label with its colon (`Vencimiento:` → `Échéance :`) and counted phrases as patterns (`{0} unidades pendientes`).
- A label joined to a name (`Cantidad de <producto>`, `Ordenar por <columna>`) translates its fixed part with `GamaI18n.t()` when rendered; the name stays as entered.
- Some server functions (HR, attendance, payroll) answer in English. `locales/server-messages.tsv` maps each of those messages to its Spanish source text, which `catalog.tsv` translates; the compiler rejects a mapping without a catalogue row. `t()` applies it to the whole message or to the part after `Label: `, so the Spanish interface shows Spanish too.
- Customer-facing documents and e-mails (PDF quotes, invoices, purchase orders, delivery proofs, payment reminders) stay in Spanish whatever the interface language: they are written for Ecuadorian customers and suppliers.

Option values are made explicit before translating their visible labels. Module navigation, access filtering and sidebar visibility use stable module IDs. Saved records, enum values, currencies and financial calculations are unchanged. User-authored commercial descriptions and stored documents retain their original content.

The runtime observes added nodes and changed presentation text, with batched updates. It does not replace innerHTML or patch DOM prototypes. The catalogue and runtime are included in the service-worker app shell for offline reuse after installation.

## Verification

`tests/i18n.spec.js` covers persistence, live switching, dynamic sales forms, mobile layout, customer data, form values, option values, notifications and role/sidebar visibility; `tests/i18n-hr.spec.js` covers Human resources in French and the empty-tag rule; `tests/i18n-coverage.spec.js` checks that the catalogue is complete in the three languages and that the generated file and every marked text match it, walks every module and tab in French and English (administrator, client and HR roles) and fails on any Spanish left on screen, and checks server-composed alert details. Run them with the existing Playwright suite. When adding a label, update all three catalogue columns, rebuild, and verify its relevant screen in French and English.
