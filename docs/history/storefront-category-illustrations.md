# Illustrations des catégories GAMA

Treize visuels originaux créés le 5 octobre 2026 avec l’outil intégré de génération d’images. Les fichiers WebP de ce dossier sont prêts pour le web : 512 × 512 pixels, qualité 84, environ 248 Kio pour la série. Les illustrations représentent une catégorie ; elles ne sont pas les photographies des références vendues.

La correspondance catégorie/fichier/texte alternatif est dans `config/storefront-category-images.json`. `npm run build:storefront` copie les fichiers dans le paquet public et versionne leurs URL par contenu. Les noms de catégories sont rapprochés sans distinction de casse, d’accents ni d’espaces répétés. Les futures catégories sans illustration conservent le repli sur leur photographie produit.

## Prompt commun

Use case: product-mockup. Asset type: one square category illustration for GAMA's professional B2B online catalogue, displayed as a small image inside a white category tile. Create a polished photorealistic studio still life. Seamless pure white background, natural object materials and soft realistic shadows. Arrange only the specified representative objects in a compact balanced central group, entirely inside the frame with generous white margins. Clear silhouettes, eye-level to gentle three-quarter view, camera framing consistent across a product catalogue. Restrained teal blue and orange accents where natural, with mostly neutral white, light wood and metal materials; match a clean professional distribution website. No text, typography, labels, logos, watermarks, prices, borders, collage or extra categories. A single complete square image, not a grid. These are generic category illustrations, not specific branded products.
